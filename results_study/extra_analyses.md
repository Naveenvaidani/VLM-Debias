## 2. Open gate: is it the initial value or the learnability?

The open gate is learnable like the learned gate, but starts at tanh = 0.995 instead of 0. Same seeds (0-4), same alignment budget.

| Task | Seeds | Learned (α=0) | Open (α=3, learnable) | Fixed (1) | Open − learned (p) | Fixed − open (p, two-sided) | final tanh, open |
| :--- | :---: | :---: | :---: | :---: | :---: | :---: | :---: |
| waterbirds | 5 | 61.9 ± 12.9 | 71.8 ± 1.8 | 72.9 ± 1.2 | +9.9 (0.063) | +1.1 (0.3) | 0.994 |
| watermark_p0.95 | 5 | 49.7 ± 17.2 | 66.8 ± 5.2 | 72.1 ± 7.3 | +17.1 (0.023) | +5.3 (0.22) | 0.994 |

Reading: a learnable gate that *starts* open stays open (tanh ≈ 0.994) and matches the fixed gate. The harm comes from initialising the gate at zero, not from making it learnable. Caveat: at α = 3 the gate gradient is scaled by 1 − tanh² ≈ 0.01, so the open gate moves little; it is learnable in form, nearly fixed in practice.

## 4. 10× longer alignment (3,000 steps vs 300), seeds 0-2

| Task | Alignment | Learned | Fixed | Fixed − learned | tanh α after alignment |

| watermark_p0.95 | 3,000 steps | 4.1 ± 1.7 | 59.5 ± 6.8 | +55.4 | -0.00020 (peak abs 0.0032) |

Reading: ten times more alignment does not open the gate (peak |tanh α| 0.003, final −0.0002), and the learned-gate model collapses to the shortcut (WGA 11 and 4: it predicts the spurious class for the minority groups), while the fixed gate changes little (−2.7 and −10.1). Longer alignment widens the gap rather than closing it, which answers the 'Flamingo trains longer' objection for our regime.

## 6. How much visual signal passes the gate (injection ratio ‖injected‖ / ‖text‖, test set)

| Run set | Learned | Open | Fixed | Runs (learned / open / fixed) |
| :--- | :---: | :---: | :---: | :---: |
| Qwen, ERM (r4-inject + r4-wm-seeds) | 3.5 (range 1.2–7.5) | 124.3 (range 106.3–145.2) | 112.4 (range 94.9–128.9) | 6 / 4 / 6 |
| Qwen, open-gate job | – | 104.7 (range 88.6–121.1) | – | 0 / 10 / 0 |
| Qwen, Group DRO | 4.1 (range 3.0–6.1) | – | 102.6 (range 92.0–114.3) | 4 / 0 / 4 |
| SigLIP-large, ERM | 7.9 (range 3.2–13.7) | – | 110.1 (range 108.7–111.8) | 3 / 0 / 3 |

Reading: the learned gate passes about 15–35× less visual signal than the fixed or open gate (raw ratios; the text-embedding norm of Qwen3.5 is small, so values above 1 are expected). Across the 13 learned-gate runs, injection ratio vs WGA: Spearman ρ = 0.33 (p = 0.27). So the pathway is not closed: with tanh α ≈ 0.003 the injected signal is still 1–7× the text-embedding norm, because the output projection grows to compensate, and the gate value alone understates the injection. But it stays an order of magnitude below the fixed gate, and within the learned-gate runs its size does not predict WGA. The gate changes *how much* visual signal is injected, not whether any is.
